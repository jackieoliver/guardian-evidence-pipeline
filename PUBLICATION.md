# Publication scope

This is a curated source-code edition of work built by Jackie Oliver at Haptica. It starts with a clean commit rather than carrying private repository history forward. Authorship of external dependencies remains with their respective authors.

## Included

Implementation files, build definitions, selected automated tests, synthetic fixtures, and an engineering README. Names and machine paths in fixtures are generic examples. Build caches, local test output, and scanner reports are not published.

## Excluded

- Recordings, screenshots of real activity, transcripts, and captured source documents.
- Personal wiki pages, biographies, context archives, private interpretation prompts, and populated databases.
- Credentials, provisioning files, cloud/OAuth account identifiers, signing-team settings, and workstation configuration.
- Historical repository objects, release archives, and deployment logs.

Secret scanning and targeted review were applied to the publication tree before its initial commit. Scanning is not a guarantee; keeping only code and synthetic fixtures reduces the material exposed. Runtime use can create sensitive data locally, which should remain outside version control.

## Attribution

The implementation is presented as Jackie's work, as confirmed by its author. Third-party package references, copyright notices, and existing licenses are retained. No new blanket license is asserted where the source did not provide one. See the README for external models, services, and other dependencies.
